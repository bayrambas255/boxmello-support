การควบคุมข้อมูล

ข้อมูลของคุณและการลบ

ไม่มีบัญชี Boxmello ไฟล์บันทึกในอุปกรณ์ ข้อความขอความช่วยเหลือ และบันทึกของบุคคลที่สามมีวิธีลบต่างกัน

วันที่มีผลและอัปเดตล่าสุด: 14 ตุลาคม 2026 · v1.0

1. ก่อนลบ

การลบแอปอาจทำให้สูญเสียความคืบหน้าและเหรียญที่ยังไม่ได้ใช้อย่างถาวรหากคุณกำลังแก้ปัญหา โปรดติดต่อขอความช่วยเหลือก่อน กู้คืนรายการซื้อจะกู้คืนของตกแต่งถาวรที่เข้าเกณฑ์ ไม่ใช่ยอดเหรียญหรือความคืบหน้าของปริศนา

ไม่มีปุ่มลบข้อมูลหรือลบบัญชีโดยเฉพาะในเกม ผู้พัฒนาไม่มีสำเนาไฟล์บันทึกของคุณบนเซิร์ฟเวอร์ และไม่สามารถรีเซ็ตหรือกู้คืนจากระยะไกล

2. ลบข้อมูลแอปในอุปกรณ์

  1. บน iPhone หรือ iPad ให้เปิด การตั้งค่า → ทั่วไป → พื้นที่จัดเก็บข้อมูล iPhone / พื้นที่จัดเก็บข้อมูล iPad → Boxmello
  2. เลือก ลบแอป และยืนยัน เอาแอปที่ไม่ได้ใช้ออกจะเก็บเอกสารและข้อมูลไว้ จึงไม่ใช่การทำงานเดียวกัน
  3. ตรวจสอบอุปกรณ์อื่นที่ติดตั้ง Boxmello แต่ละอุปกรณ์อาจมีไฟล์บันทึกของตนเอง

วิธีนี้ลบพื้นที่จัดเก็บของแอป Boxmello จากอุปกรณ์นั้น รวมถึงไฟล์บันทึกและไฟล์กู้คืนในอุปกรณ์ การติดตั้งใหม่จะสร้างไฟล์บันทึกใหม่ เว้นแต่ข้อมูลสำรองของระบบปฏิบัติการหรือการย้ายข้อมูลจะนำข้อมูลเดิมกลับมา ประวัติการซื้อใน App Store ไม่ถูกลบ

3. จัดการข้อมูลสำรองแยกต่างหาก

ข้อมูลแอปอาจยังอยู่ในข้อมูลสำรอง iCloud หรือคอมพิวเตอร์ตามการตั้งค่า ตรวจสอบ Boxmello ในการตั้งค่าการสำรอง iCloud ของอุปกรณ์ และหากต้องการลบสำเนานั้นด้วย ให้ลบข้อมูลสำรองหรือไม่นำไปรวมในการสำรอง ตรวจสอบข้อมูลสำรอง Mac หรือ PC แยกต่างหาก ชื่อเมนู Apple อาจต่างกันตามเวอร์ชันระบบปฏิบัติการ ดูคู่มือพื้นที่จัดเก็บข้อมูล iCloud ของ Apple การลบข้อมูลสำรองอาจกระทบการกู้คืนข้อมูลอื่น โปรดตรวจสอบสิ่งที่เลือก

4. ขอให้ลบการติดต่อขอความช่วยเหลือ

ส่งอีเมลไปที่ bayrambas255@icloud.com โดยใช้หัวข้อ คำขอด้านความเป็นส่วนตัวของ Boxmello หากเป็นไปได้ให้ใช้ที่อยู่อีเมลที่เคยติดต่อขอความช่วยเหลือ และระบุ:

  • ชื่อและนามสกุล
  • คำขอ: ลบ เข้าถึง แก้ไข หรือสิทธิ์ด้านความเป็นส่วนตัวอื่น
  • การติดต่อที่เกี่ยวข้องหรือวันที่โดยประมาณ
  • ที่อยู่ตอบกลับหากต่างจากที่อยู่ผู้ส่ง

อย่าส่งรหัสผ่าน หมายเลขบัตรชำระเงินครบถ้วน หรือเอกสารยืนยันตัวตนโดยไม่ได้รับการร้องขอ เราอาจขอการยืนยันที่สมเหตุสมผลหรือรายละเอียดตามขั้นตอนทางกฎหมายที่ใช้บังคับ เราจะลบหรือทำให้ข้อมูลที่ผู้พัฒนาเก็บไว้ไม่สามารถระบุตัวบุคคลได้เมื่อเข้าเงื่อนไขทางกฎหมาย และอธิบายข้อมูลที่ต้องเก็บตามหน้าที่หรือข้อเรียกร้องทางกฎหมาย คำขอจะได้รับคำตอบภายในกำหนดตามกฎหมาย รวมถึงไม่เกิน 30 วันเมื่ออยู่ภายใต้ KVKK แห่งตุรกี

คำขอความช่วยเหลือและคำขอลบทั่วไปใช้วิธีข้างต้นได้ คำขออย่างเป็นทางการตาม KVKK ควรทำเป็นภาษาตุรกีและส่งจากที่อยู่อีเมลที่ได้ให้และลงทะเบียนไว้กับผู้พัฒนาก่อนแล้ว หรือใช้วิธีอื่นที่ประกาศที่ใช้บังคับอนุญาต มาตรา 5 ของประกาศกำหนดให้คำขออย่างเป็นทางการมีรายละเอียดที่กำหนด เช่น ชื่อ คำขอ ที่อยู่สำหรับส่งเอกสาร และข้อมูลระบุตัวตนที่เกี่ยวข้อง ดูขั้นตอนยื่นคำขออย่างเป็นทางการ อย่าส่งสำเนาเอกสารยืนยันตัวตนโดยไม่ได้รับการร้องขอ

5. บันทึกของ Apple และ GitHub

การลบ Boxmello หรือส่งอีเมลถึงผู้พัฒนาไม่ลบประวัติการเรียกเก็บเงินของ Apple ข้อมูลบัญชี Apple หรือบันทึกความปลอดภัยของโฮสติ้ง GitHub สำหรับบันทึกที่แต่ละรายควบคุม ให้ใช้เครื่องมือข้อมูลและความเป็นส่วนตัวของ Apple หรือช่องทางติดต่อในประกาศความเป็นส่วนตัวของ GitHub สำเนาสำรองของ Apple ก็ต้องจัดการผ่านการตั้งค่า Apple แยกต่างหาก

การลบไฟล์บันทึกในอุปกรณ์ไม่ทำให้การซื้อถูกยกเลิก ไม่เป็นคำขอคืนเงิน และไม่เพิกถอนสิทธิ์ของตกแต่งถาวรที่ยังใช้ได้ Apple อาจทำให้สิทธิ์นั้นกลับมาใช้งานผ่านกู้คืนรายการซื้อ

6. ข้อมูลเพิ่มเติมเกี่ยวกับสิทธิ์ของคุณ

นโยบายความเป็นส่วนตัวอธิบายวัตถุประสงค์การประมวลผล ผู้รับข้อมูล ฐานทางกฎหมาย การเก็บรักษา และสิทธิ์ตาม KVKK แห่งตุรกีและกฎหมายความเป็นส่วนตัวอื่นที่ใช้บังคับ คุณสามารถติดต่อหน่วยงานคุ้มครองข้อมูลที่เกี่ยวข้องตามขั้นตอนร้องเรียนที่ใช้บังคับ
