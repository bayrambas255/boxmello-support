นโยบายความเป็นส่วนตัว

คำอธิบายเกี่ยวกับไฟล์บันทึกในอุปกรณ์ของ Boxmello บริการ Apple อีเมลขอความช่วยเหลือ และเว็บไซต์นี้ เอกสารนี้ยังเป็นประกาศของเราตามกฎหมายคุ้มครองข้อมูลส่วนบุคคลของตุรกี (KVKK) ด้วย

วันที่มีผลและอัปเดตล่าสุด: 14 ตุลาคม 2026 · v1.0

1. ใครเป็นผู้รับผิดชอบ?

Boxmello ให้บริการโดย Bayram Baş ในตุรกี สำหรับข้อมูลส่วนบุคคลที่ผู้พัฒนาจัดการ Bayram Baş เป็นผู้ควบคุมข้อมูล ติดต่อ: bayrambas255@icloud.com

นโยบายนี้ครอบคลุมเกม iOS/iPadOS ปัจจุบัน เว็บไซต์ขอความช่วยเหลือนี้ และการติดต่อกับผู้พัฒนา Apple และ GitHub ยังประมวลผลข้อมูลสำหรับบริการของตนตามประกาศความเป็นส่วนตัวของแต่ละราย

2. ข้อมูลที่จัดเก็บในเกม

การเล่นเวอร์ชัน App Store ตามปกติไม่ส่งไฟล์บันทึกเกมไปยังเซิร์ฟเวอร์ของผู้พัฒนา Boxmello ไม่มีบัญชีเกม SDK โฆษณา SDK วิเคราะห์ของบุคคลที่สาม หรือการติดตามข้ามแอป ไม่ขอเข้าถึงตำแหน่งที่ตั้ง รายชื่อผู้ติดต่อ กล้อง หรือไมโครโฟนของคุณ

แอปจัดเก็บตัวระบุโปรไฟล์ในอุปกรณ์ที่สร้างแบบสุ่ม ความคืบหน้าของด่าน คะแนนและดาว สถานะปริศนาที่กำลังเล่น ยอดเหรียญและตัวช่วย ของตกแต่ง รางวัลรายวัน สถานะบทสอน และการตั้งค่า รวมถึงบันทึกการตรวจสอบการซื้อ เช่น ตัวระบุสินค้าและธุรกรรม วันที่ประมวลผล สถานะการคืนเงิน และสิทธิ์ในรายการซื้อถาวร ข้อมูลเหล่านี้ช่วยบันทึกเกม ป้องกันการส่งมอบรายการซื้อซ้ำ และปรับตามการเปลี่ยนแปลงการซื้อที่ตรวจสอบแล้ว

ไฟล์บันทึกและสำเนาสำหรับกู้คืนอยู่ในอุปกรณ์เดียวกัน ไม่ใช่ข้อมูลสำรองคลาวด์ที่แยกเป็นอิสระ คุณสมบัติสำรองข้อมูลหรือย้ายข้อมูลของ Apple อาจรวมข้อมูลเหล่านี้ตามการตั้งค่าของคุณ ผู้พัฒนาไม่มีสิทธิ์เข้าถึงไฟล์บันทึกในอุปกรณ์ของคุณจากระยะไกล

ข้อมูลบันทึกในอุปกรณ์และข้อมูล StoreKit ประมวลผลทางอิเล็กทรอนิกส์และโดยอัตโนมัติบนอุปกรณ์ เพื่อให้บริการเกมและตรวจสอบการซื้อ โดยอาศัยฐานการปฏิบัติตามสัญญาตามมาตรา 5(2)(c) ของ KVKK แห่งตุรกี

3. การซื้อและข้อมูลที่ Apple ให้

Apple จัดการการชำระเงิน App Store ผ่าน StoreKit Boxmello ได้รับข้อมูลธุรกรรมและสิทธิ์ที่ตรวจสอบแล้วบนอุปกรณ์ของคุณเพื่อส่งมอบรายการซื้อและจัดการการกู้คืนหรือคืนเงิน ผู้พัฒนาไม่ได้รับรายละเอียดบัตรชำระเงินหรือรหัสผ่านบัญชี Apple ของคุณ

Apple อาจให้สรุปยอดขายและรายงานประสิทธิภาพหรือการปิดตัวเองของแอปแก่ผู้พัฒนา การแชร์ข้อมูลการใช้งานและการปิดตัวเองขึ้นอยู่กับบริการ Apple และตัวเลือกบนอุปกรณ์ของคุณ ซึ่งแยกจาก SDK วิเคราะห์ภายใน Boxmello ดูการวิเคราะห์แอปและความเป็นส่วนตัว และนโยบายความเป็นส่วนตัวของ Apple ตรวจสอบการแชร์ได้ใน iOS การตั้งค่า → ความเป็นส่วนตัวและความปลอดภัย → การวิเคราะห์และการปรับปรุง

รายงานการวินิจฉัยที่ผู้พัฒนาเก็บไว้ใช้เพื่อระบุและแก้ไขข้อผิดพลาด โดยอาศัยประโยชน์โดยชอบด้วยกฎหมายตามมาตรา 5(2)(f) ของ KVKK แห่งตุรกี และคำนึงถึงดุลยภาพกับสิทธิ์ของคุณ สำเนาที่ผู้พัฒนาเก็บไว้จะเก็บเฉพาะช่วงที่จำเป็นต่อการตรวจสอบและแก้ไขปัญหา หรือปฏิบัติตามหน้าที่หรือข้อเรียกร้องทางกฎหมาย จากนั้นลบหรือทำให้ไม่สามารถระบุตัวบุคคลได้ Apple ควบคุมการเก็บรายงานในบริการของตน

4. การติดต่อขอความช่วยเหลือและฐานทางกฎหมาย

หากคุณส่งอีเมลถึงผู้พัฒนา เราจะได้รับที่อยู่อีเมล ชื่อผู้ส่ง ข้อความ และไฟล์แนบหรือรายละเอียดทางเทคนิคที่คุณเลือกให้ผ่าน iCloud Mail การตอบทางอีเมลต้องใช้ที่อยู่อีเมลและข้อมูลที่เพียงพอเกี่ยวกับคำถามของคุณ คุณเล่นได้โดยไม่ต้องติดต่อเรา โปรดหลีกเลี่ยงการส่งข้อมูลส่วนบุคคลที่มีความอ่อนไหว

ข้อมูลการขอความช่วยเหลือใช้เพื่อตอบคำขอ ตรวจสอบปัญหา ช่วยเรื่องการซื้อ แก้ไขปัญหาที่รายงาน หรือดำเนินการตามคำขอด้านความเป็นส่วนตัว ไม่ใช้เพื่อโฆษณา รายชื่อรับจดหมาย ขายข้อมูลส่วนบุคคล หรือตัดสินใจเกี่ยวกับคุณโดยอัตโนมัติ

วัตถุประสงค์และฐานทางกฎหมายของข้อมูลขอความช่วยเหลือที่ผู้พัฒนาจัดการ
วัตถุประสงค์ฐานตาม KVKK แห่งตุรกี
ตอบคำขอความช่วยเหลือเกี่ยวกับเกมหรือการซื้อที่จำเป็นต่อการให้บริการเกมมาตรา 5(2)(c): การปฏิบัติตามสัญญา
ตรวจสอบข้อผิดพลาดและป้องกันการใช้การติดต่อขอความช่วยเหลือในทางที่ผิด โดยเคารพสิทธิ์ของคุณมาตรา 5(2)(f): ประโยชน์โดยชอบด้วยกฎหมาย
ตอบคำขอข้อมูลตามกฎหมายหรือการเปิดเผยที่จำเป็นมาตรา 5(2)(ç): หน้าที่ตามกฎหมาย
ระงับข้อพิพาท หรือก่อตั้ง ใช้ หรือต่อสู้ข้อเรียกร้องทางกฎหมายมาตรา 5(2)(e): การคุ้มครองสิทธิ์

หากกฎหมายความเป็นส่วนตัวอื่นที่ใช้บังคับกำหนดฐานที่ต่างออกไป ให้ใช้ฐานสัญญา หน้าที่ตามกฎหมาย หรือประโยชน์โดยชอบด้วยกฎหมายที่สอดคล้องกัน หากกิจกรรมทางเลือกอื่นต้องได้รับความยินยอม ต้องขอแยกต่างหาก การอ่านนโยบายนี้ไม่ถือเป็นการให้ความยินยอม

5. โฮสติ้งเว็บไซต์และคุกกี้

เว็บไซต์ขอความช่วยเหลือแบบคงที่นี้ไม่มีคุกกี้ การจัดเก็บในเบราว์เซอร์ โฆษณา แบบฟอร์มติดต่อ วิดเจ็ตสังคมออนไลน์แบบฝัง หรือเครื่องมือวิเคราะห์ผู้เข้าชมที่ผู้พัฒนาเพิ่มไว้ รูปภาพและรูปแบบหน้าให้บริการพร้อมเว็บไซต์ ไม่ใช้บริการฟอนต์ของบุคคลที่สาม

GitHub Pages เป็นผู้ให้บริการโฮสติ้ง GitHub ระบุว่าบันทึกที่อยู่ IP ของผู้เข้าชมเพื่อความปลอดภัย รวมถึงการเข้าชมโดยไม่ได้ลงชื่อเข้าใช้ GitHub ควบคุมบันทึกโฮสติ้งเหล่านี้ ผู้พัฒนาไม่ได้รับบันทึกผู้เข้าชมรายบุคคลผ่านเว็บไซต์นี้ ดูการเก็บข้อมูลของ GitHub Pages และประกาศความเป็นส่วนตัวของ GitHub การเปิดลิงก์ภายนอกจะพาคุณไปยังบริการของผู้ให้บริการนั้น

6. ผู้รับข้อมูลและการประมวลผลนอกประเทศ

Apple ให้บริการชำระเงิน รายงานแพลตฟอร์ม สำรองข้อมูลอุปกรณ์เมื่อเปิดใช้งาน และ iCloud Mail ส่วน GitHub ให้บริการโฮสติ้งและความปลอดภัยของเว็บไซต์ Bayram Baş และบริการอีเมลที่ใช้ส่งข้อความเป็นผู้จัดการการติดต่อขอความช่วยเหลือ อาจเปิดเผยข้อมูลต่อหน่วยงานที่มีอำนาจเมื่อกฎหมายกำหนด หรือต่อที่ปรึกษาวิชาชีพเมื่อจำเป็นสำหรับข้อเรียกร้องทางกฎหมาย โดยจำกัดเฉพาะข้อมูลที่จำเป็น

ข้อความขอความช่วยเหลือรับและจัดเก็บผ่าน iCloud Mail ของ Apple เนื้อหาข้อความ ข้อมูลผู้ส่ง และไฟล์แนบอาจประมวลผลบนโครงสร้างพื้นฐานนอกตุรกีหรือนอกประเทศที่คุณพำนัก GitHub ยังประมวลผลบันทึก IP ของผู้เข้าชมบนโครงสร้างพื้นฐานระหว่างประเทศเพื่อให้บริการและรักษาความปลอดภัยของเว็บไซต์นี้ ประกาศความเป็นส่วนตัวของ Apple และ GitHub อธิบายบริการเหล่านี้ การเข้าชมเว็บไซต์หรือส่งอีเมลขอความช่วยเหลือไม่ถือเป็นความยินยอมในการโอนข้อมูลระหว่างประเทศ หากมีคำถามเกี่ยวกับการโอนข้อมูลเฉพาะกรณีที่ผู้พัฒนาเก็บไว้ โปรดติดต่อช่องทางข้างต้น

7. ระยะเวลาเก็บรักษาและความปลอดภัย

ไฟล์บันทึกในอุปกรณ์จะคงอยู่จนกว่าข้อมูลแอปถูกลบ ส่วนข้อมูลสำรองในอุปกรณ์หรือคลาวด์ควบคุมแยกกัน การติดต่อขอความช่วยเหลือจะเก็บเฉพาะระยะเวลาที่จำเป็นเพื่อดำเนินการตามคำขอและติดตามผล ปฏิบัติตามหน้าที่ตามกฎหมายที่ใช้บังคับ หรือก่อตั้ง ใช้ หรือต่อสู้ข้อเรียกร้องทางกฎหมาย ระยะเวลาขึ้นอยู่กับปัญหา ข้อพิพาทที่ยังไม่ยุติ และระยะเวลาเก็บรักษาหรืออายุความตามกฎหมาย ข้อมูลที่ไม่จำเป็นต่อวัตถุประสงค์เหล่านี้แล้วจะถูกลบหรือทำให้ไม่สามารถระบุตัวบุคคลได้

Apple และ GitHub กำหนดระยะเวลาเก็บบันทึกที่ตนควบคุม การติดต่อที่ผู้พัฒนาเก็บไว้มีมาตรการป้องกันที่สมเหตุสมผล แต่ไม่มีวิธีจัดเก็บหรือส่งข้อมูลใดรับประกันความปลอดภัยได้ทั้งหมด อย่าใส่รหัสผ่าน ข้อมูลบัตรครบถ้วน หรือเอกสารยืนยันตัวตนที่ไม่จำเป็นในข้อความขอความช่วยเหลือ

8. สิทธิ์ด้านความเป็นส่วนตัวของคุณ

ตามมาตรา 11 ของ KVKK แห่งตุรกี คุณสามารถสอบถามว่ามีการประมวลผลข้อมูลของคุณหรือไม่ ขอข้อมูลเกี่ยวกับการประมวลผล วัตถุประสงค์และการใช้ ทราบผู้รับข้อมูลในประเทศหรือต่างประเทศ ขอแก้ไข ลบ หรือทำลายเมื่อเข้าเงื่อนไขทางกฎหมาย และขอให้แจ้งการแก้ไขหรือการลบเหล่านั้นแก่ผู้รับข้อมูล คุณสามารถคัดค้านผลเสียที่เกิดจากการวิเคราะห์โดยระบบอัตโนมัติเพียงอย่างเดียว และเรียกค่าชดเชยจากการประมวลผลที่ไม่ชอบด้วยกฎหมาย Boxmello ไม่ตัดสินใจโดยอัตโนมัติเช่นนั้น

กฎหมายอื่นที่ใช้บังคับอาจให้สิทธิ์เข้าถึง โอนย้าย จำกัดการประมวลผล คัดค้าน และถอนความยินยอมเพิ่มเติม คุณสามารถร้องเรียนต่อหน่วยงานคุ้มครองข้อมูลที่เกี่ยวข้อง สำหรับตุรกี ดูคู่มือสิทธิ์ตาม KVKK

ส่งอีเมลถึงผู้พัฒนาจากที่อยู่ที่ใช้ติดต่อ โดยอธิบายคำขอ เราอาจขอการยืนยันในสัดส่วนที่เหมาะสมและรายละเอียดที่ขั้นตอนที่ใช้บังคับกำหนด คำขอจะได้รับคำตอบภายในกำหนดตามกฎหมาย รวมถึงไม่เกิน 30 วันเมื่ออยู่ภายใต้ KVKK หากมีข้อยกเว้นที่กฎหมายกำหนดให้เก็บข้อมูลไว้ เราจะอธิบายให้ทราบ ดูคู่มือข้อมูลและการลบ ผู้พัฒนาไม่สามารถตรวจดูหรือลบไฟล์บันทึกที่อยู่เฉพาะในอุปกรณ์ของคุณจากระยะไกล หรือลบบันทึกที่ Apple หรือ GitHub ควบคุม

9. เด็กและครอบครัว

เกมไม่กำหนดให้เด็กหรือผู้เล่นคนอื่นต้องมีบัญชีหรือให้ข้อมูลส่วนตัวเพื่อเล่น เราไม่ขอให้เด็กส่งข้อมูลส่วนตัวและไม่ใช้ข้อมูลของเด็กเพื่อโฆษณา ผู้ปกครองหรือผู้แทนโดยชอบธรรมควรเป็นผู้จัดการคำถามเรื่องความช่วยเหลือและการซื้อสำหรับเด็ก หากคุณเชื่อว่าเด็กส่งข้อมูลส่วนตัวมา โปรดติดต่อผู้พัฒนาเพื่อให้ตรวจสอบและลบเมื่อเหมาะสม ปฏิบัติตามระดับอายุที่แสดงใน App Store และข้อกำหนดการอนุญาตจากผู้ปกครองที่ใช้บังคับ

10. รุ่นเบต้าและการทดสอบเล่นแบบเลือกได้

รุ่น TestFlight หรือรุ่นพัฒนาอาจมีโหมดทดสอบเล่นแบบเลือกได้ที่นักวิจัยเป็นผู้เปิด เมื่อเปิด จะบันทึกรหัสผู้เข้าร่วม เหตุการณ์การเล่น เวลา และข้อมูลรุ่นลงในไฟล์ในอุปกรณ์ ไม่มีการอัปโหลดอัตโนมัติ ผู้ดำเนินการทดลองสามารถตั้งใจส่งออกผ่านเมนูแชร์ของอุปกรณ์ รุ่น App Store ปกติไม่เปิดใช้โหมดนี้ การศึกษาที่จัดขึ้นต้องอธิบายวัตถุประสงค์ ผู้รับข้อมูล ระยะเวลาเก็บ และทางเลือกในการเข้าร่วมก่อนเก็บหรือส่งออกข้อมูลการศึกษา บริการ TestFlight ของ Apple มีข้อกำหนดความเป็นส่วนตัวของตนเอง
