データの管理

データと削除

Boxmelloアカウントはありません。端末のセーブデータ、サポートメッセージ、第三者の記録には、それぞれ異なる削除方法があります。

施行日・最終更新日：2026年10月14日 · v1.0

1. 削除する前に

アプリを削除すると、進行状況と未使用のコインを永久に失うことがあります。問題を解決したい場合は、まずサポートにご連絡ください。「購入を復元」で復元できるのは対象となる恒久的な装飾であり、コイン残高やパズルの進行状況ではありません。

ゲーム内に専用のデータ消去やアカウント削除ボタンはありません。開発者はセーブデータのサーバーコピーを保有せず、遠隔でリセットや復旧はできません。

2. 端末内のアプリデータを削除する

  1. iPhoneまたはiPadで設定 → 一般 → iPhoneストレージ / iPadストレージ → Boxmelloを開いてください。
  2. アプリを削除を選んで確認してください。アプリを取り除くは書類とデータを残すため、同じ操作ではありません。
  3. Boxmelloをインストールしている他の端末も確認してください。各端末にそれぞれのセーブデータがある場合があります。

これにより、端末内のセーブデータや復旧用ファイルを含むBoxmelloのアプリ領域が、その端末から削除されます。オペレーティングシステムのバックアップや移行によって以前のデータが復元されない限り、再インストールすると新しいセーブデータが作られます。App Storeの購入履歴は削除されません。

3. バックアップは別に管理する

設定によっては、アプリデータがiCloudやコンピュータのバックアップに残る場合があります。端末のiCloudバックアップ設定でBoxmelloを確認し、そのコピーも削除したい場合は、該当するバックアップデータを削除するかバックアップ対象から除外してください。MacやPCのバックアップも別に確認してください。Appleのメニュー名はオペレーティングシステムのバージョンによって異なります。AppleのiCloudストレージの案内をご確認ください。バックアップの削除は他のデータの復旧にも影響するため、選択する項目を確認してください。

4. サポートのやり取りの削除を依頼する

件名をBoxmelloのプライバシーに関する依頼としてbayrambas255@icloud.comへメールをお送りください。可能であれば以前サポートへの連絡に使用したアドレスから、次の事項を記載してください。

  • 氏名。
  • 削除、アクセス、訂正など、ご希望のプライバシーに関する権利。
  • 対象となるやり取り、またはおおよその日付。
  • 送信元と異なる場合は返信先アドレス。

求められていないパスワード、完全な支払いカード番号、本人確認書類は送信しないでください。合理的な確認や、適用される法的手続に必要な詳細をお願いすることがあります。法的条件を満たす場合は開発者が保有するデータを削除または匿名化し、法的義務や法的請求のため保存する必要があるデータは説明します。ご依頼には適用される法定期限内に回答し、トルコのKVKKに基づく場合は遅くとも30日以内に回答します。

通常のサポートや削除依頼には上記の方法を利用できます。正式なKVKKの申請はトルコ語で作成し、事前に開発者へ提供され登録されたメールアドレスから送信するか、適用される通達で認められた別の方法を使用してください。通達の第5条は、正式な申請に氏名、請求内容、送達先住所、該当する本人識別情報などの所定の情報を含めるよう求めています。公式の申請手続をご確認ください。本人確認書類のコピーを求められていないのに送信しないでください。

5. AppleとGitHubの記録

Boxmelloの削除や開発者へのメールでは、Appleの請求履歴、Apple Accountのデータ、GitHubのホスティングのセキュリティログは削除されません。各社が管理する記録については、AppleのデータとプライバシーのツールまたはGitHubのプライバシー声明に記載された連絡方法を利用してください。Appleのバックアップコピーも、Appleの設定で別に管理する必要があります。

端末内のセーブデータを削除すること自体は、購入の取消し、返金依頼、有効な恒久的な装飾の利用権の取消しにはなりません。Appleは「購入を復元」を通じてその利用権を再び提供する場合があります。

6. 権利についての詳細

プライバシーポリシーでは、処理目的、提供先、法的根拠、保存期間、トルコのKVKKおよび他の適用されるプライバシー上の権利について説明しています。適用される苦情手続に従い、関係するデータ保護当局へ申し立てることができます。
