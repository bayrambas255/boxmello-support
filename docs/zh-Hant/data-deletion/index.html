自主管理

你的資料與刪除

Boxmello 沒有帳號。設備存檔、支援郵件及第三方記錄各有不同的刪除方式。

生效及最後更新日期：2026年10月14日 · v1.0

1. 刪除前須知

刪除 App 可能導致進度和未使用金幣永久丟失。如果你正在嘗試解決問題，請先聯繫支援。回復購買可恢復符合條件的永久裝飾，但不會恢復金幣餘額或解謎進度。

遊戲內沒有專門的資料清除或帳號刪除按鈕。開發者沒有你存檔的服務器副本，因此無法遠程重置或恢復。

2. 移除本地 App 資料

  1. 在 iPhone 或 iPad 上打開設定 → 一般 → iPhone 儲存空間 / iPad 儲存空間 → Boxmello。
  2. 選擇刪除 App並確認。卸載 App會保留文件和資料，因此並非同一操作。
  3. 檢查安裝了 Boxmello 的其他設備；每台設備可能有自己的本地存檔。

這會從該設備移除 Boxmello 的 App 容器，包括本地存檔與恢復文件。除非操作系統備份或遷移恢復了舊資料，否則重新安裝會創建新存檔。這不會刪除你的 App Store 購買歷史。

3. 單獨管理備份

根據設置，App 資料可能保留在 iCloud 或電腦備份中。請在設備的 iCloud 備份設置中查看 Boxmello，如果也希望刪除該副本，請移除其備份資料或將其排除在備份之外。Mac 或 PC 備份也需單獨檢查。Apple 菜單名稱可能因操作系統版本而異；請參閱Apple iCloud 儲存空間指南。刪除備份可能影響其他資料的恢復，請檢查你選擇的內容。

4. 請求刪除支援通信

請以Boxmello 隱私請求為主題，發送郵件至bayrambas255@icloud.com。如有可能，請使用之前聯繫支援時的郵箱地址，並提供：

  • 你的姓名。
  • 請求內容：刪除、訪問、更正或其他隱私權利。
  • 相關通信或大致日期。
  • 若與發件地址不同，請提供回復地址。

請勿主動發送密碼、完整支付卡號或身份證件。我們可能要求合理驗證或適用法律程序所需的詳細資訊。在符合法律條件時，我們會刪除或匿名化開發者所持資料，並說明因法律義務或法律請求而必須保留的資料。請求會在適用法定期限內得到答復，包括土耳其 KVKK 適用時最長30天。

簡單支援和刪除請求可使用上述方式。正式 KVKK 申請應以土耳其語提出，從事先提供並在開發者處登記的郵箱地址發送，或使用適用公告允許的其他方式。公告第5條要求正式申請包含規定資訊，例如姓名、請求內容、送達地址及相關身份資訊。請參閱官方申請程序。請勿主動發送身份證件副本。

5. Apple 和 GitHub 記錄

刪除 Boxmello 或向開發者發送郵件不會刪除 Apple 帳單歷史、Apple 帳號資料或 GitHub 托管安全日誌。對於它們控制的記錄，請使用Apple 資料與隱私工具或GitHub 隱私聲明中的聯繫方式。任何 Apple 備份副本也必須通過 Apple 設置另行管理。

刪除本地存檔本身不會取消購買、提交退款請求或撤銷有效的永久裝飾使用權。Apple 可能通過回復購買再次提供該使用權。

6. 關於權利的更多資訊

隱私政策說明處理目的、接收方、法律依據、保留期限，以及你在土耳其 KVKK 和其他適用隱私法律下的權利。你可以根據適用投訴程序聯繫相關資料保護機關。
