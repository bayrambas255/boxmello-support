你的隱私

隱私政策

關於 Boxmello 本地存檔、Apple 服務、支援郵件和本網站的實用說明。本政策同時作為我們根據土耳其《個人資料保護法》（KVKK）提供的告知。

生效及最後更新日期：2026年10月14日 · v1.0

1. 誰負責處理資料？

Boxmello 由位於土耳其的Bayram Baş提供。對於開發者處理的個人資料，Bayram Baş 是資料控制者。聯繫方式：bayrambas255@icloud.com。

本政策涵蓋當前 iOS/iPadOS 遊戲、本支援網站及與開發者的通信。Apple 和 GitHub 也根據各自的隱私聲明，為其自身服務處理資訊。

2. 遊戲中儲存的資料

正常遊玩 App Store 版本時，遊戲存檔不會發送到開發者的服務器。Boxmello 沒有遊戲帳號、廣告 SDK、第三方分析 SDK 或跨 App 跟蹤。它不會請求訪問你的位置、通訊錄、相機或麥克風。

App 會儲存隨機生成的本地個人檔案標識符、關卡進度、分數和星星、當前謎題狀態、金幣與輔助道具餘額、裝飾、每日獎勵、教程狀態及設置。它還會儲存購買驗證記錄，例如商品與交易標識符、處理日期、退款狀態及永久購買使用權。這些資訊用於保存遊戲、避免重復發放購買內容及應用已驗證的購買變更。

存檔及其恢復副本位於同一台設備，並非獨立的雲備份。根據你的設置，Apple 設備備份或遷移功能可能包含這些資料。開發者無法遠程訪問你的本地存檔。

本地存檔和 StoreKit 資訊在設備上以電子和自動方式處理，用於提供遊戲和驗證購買，法律依據為土耳其 KVKK 第5條(2)(c)規定的履行合同。

3. 購買及 Apple 提供的資訊

Apple 通過 StoreKit 處理 App Store 付款。Boxmello 在你的設備上接收經驗證的交易和使用權資訊，以發放購買內容並處理恢復或退款。開發者不會收到你的支付卡資訊或 Apple 帳號密碼。

Apple 可能向開發者提供銷售摘要、App 性能或崩潰報告。使用情況和崩潰資訊的共享取決於 Apple 服務及你的設備選擇，與 Boxmello 內的分析 SDK 不同。請參閱App 分析與隱私及Apple 隱私政策。可在 iOS 設定 → 隱私權與安全性 → 分析與改進中查看共享選項。

開發者持有的診斷報告用於識別和修復故障，依據為土耳其 KVKK 第5條(2)(f)規定的正當利益，並與你的權利進行權衡。開發者持有的副本僅在調查和解決問題或履行法律義務、處理法律請求所需的期間保留，隨後刪除或匿名化。Apple 自行管理其服務中報告的保留期限。

4. 支援通信及法律依據

當你向開發者發送郵件時，你的郵箱地址、發件人姓名、郵件內容，以及你自行提供的附件或技術詳情將通過 iCloud Mail 接收。通過郵件回復需要你的郵箱地址和足以說明問題的資訊；無需聯繫支援也能遊玩。請避免發送敏感個人資料。

支援資料用於回答你的請求、調查問題、協助購買、改進已報告的問題或處理隱私請求，不用於廣告、郵件推廣名單、出售個人資料或對你作出自動化決定。

開發者處理支援資料的目的與法律依據
目的土耳其 KVKK 依據
回復提供遊戲所需的遊戲或購買支援請求第5條(2)(c)：履行合同
在尊重你權利的前提下調查故障並防止支援通信被濫用第5條(2)(f)：正當利益
回應法定資料請求或必須進行的披露第5條(2)(ç)：法律義務
解決爭議或確立、行使、維護法律請求第5條(2)(e)：保護權利

如果其他適用的隱私法律要求不同依據，則適用相應的合同、法律義務或正當利益依據。如果另一項可選活動需要同意，必須單獨徵求；閱讀本政策本身並不表示同意。

5. 網站托管和 Cookie

本靜態支援網站沒有開發者添加的 Cookie、本地儲存、廣告、聯繫表單、嵌入式社交組件或訪客分析工具。圖片和樣式隨網站提供，不使用第三方字體服務。

本網站由 GitHub Pages 托管。GitHub 表示會出於安全目的記錄訪客 IP 地址，包括未登錄狀態下的訪問。這些托管日誌由 GitHub 管理，開發者不會通過本網站接收單個訪客日誌。請參閱GitHub Pages 資料收集說明和GitHub 隱私聲明。打開外部鏈接會前往相應提供者的服務。

6. 接收方及境外處理

Apple 提供付款、平台報告、啓用後的設備備份及 iCloud Mail 服務。GitHub 提供網站托管與安全服務。支援通信由 Bayram Baş 及傳遞郵件所用的服務處理。法律要求時，資訊也可能披露給主管機關；法律請求需要時，也可能披露給專業顧問，但均限於必要範圍。

支援郵件通過 Apple 的 iCloud Mail 接收和儲存；郵件內容、發件人資訊及附件可能在土耳其或你居住國以外的基礎設施上處理。GitHub 也會在其國際基礎設施上處理訪客 IP 日誌，以提供和保護本網站。Apple 和 GitHub 的隱私聲明對這些服務作出說明。訪問本網站或發送支援郵件不被視為同意國際資料傳輸。對於涉及開發者所持資料的具體傳輸，可向上述聯繫人詢問。

7. 保留期限與安全

本地存檔保留在設備上，直至 App 資料被移除；設備或雲備份副本另行管理。支援通信僅在解決請求及相關後續事項、履行適用法律義務，或確立、行使、維護法律請求所需的期間保留。具體期間取決於問題、是否存在未解決爭議，以及適用的法定保留期限或時效。不再用於上述目的的資料將被刪除或匿名化。

Apple 和 GitHub 自行確定其控制的記錄的保留期限。開發者持有的通信會採用合理保護措施，但任何儲存或傳輸方式都無法保證絕對安全。請勿在支援郵件中包含密碼、完整卡資訊或不必要的身份證件。

8. 你的隱私權利

根據土耳其 KVKK 第11條，你可以詢問資料是否被處理，要求瞭解處理情況、目的和用途，瞭解境內外接收方，在符合法律條件時要求更正、刪除或銷毀，並要求將這些更正或刪除告知接收方。你可以對完全基於自動分析產生的不利結果提出異議，並要求賠償違法處理造成的損失。Boxmello 不作出此類自動化決定。

其他適用法律也可能賦予訪問、資料可攜帶、限制處理、反對和撤回同意的權利。你可以向相關資料保護機關投訴。有關土耳其，請參閱KVKK 權利指南。

請使用通信時的郵箱地址向開發者發送郵件，說明你的請求。我們可能要求適度驗證及適用程序所需的詳細資訊。請求會在適用的法定期限內得到答復，包括 KVKK 適用時不遲於30天。因法律要求而必須保留資料的例外情況會予以說明。請參閱資料與刪除指南。開發者無法查看或遠程刪除僅保存在你設備上的存檔，也無法刪除由 Apple 或 GitHub 控制的記錄。

9. 兒童與家庭

兒童和其他玩家無需提供帳號或個人資料即可遊玩。我們不會要求兒童發送個人資料，也不將其資料用於廣告。兒童的支援及購買問題應由家長或監護人處理。如果你認為兒童發送了個人資料，請聯繫開發者，以便審核並在適當情況下刪除。請遵守 App Store 顯示的年齡分級及適用的家長許可要求。

10. 可選的 Beta 版與遊戲測試

TestFlight 或開發版本可能包含由研究人員啓用的可選遊戲測試模式。啓用後，它會將參與者代碼、遊戲事件、時間和版本資訊寫入本地文件。這些文件不會自動上傳；實驗人員可以通過設備的分享菜單主動導出。正常 App Store 版本不會啓用此模式。任何有組織的研究都必須在收集或導出研究資料前說明目的、接收方、保留期限及參與選擇。Apple 的 TestFlight 服務有其自己的隱私條款。
