自主管理

你的数据与删除

Boxmello 没有账号。设备存档、支持邮件及第三方记录各有不同的删除方式。

生效及最后更新日期：2026年10月14日 · v1.0

1. 删除前须知

删除 App 可能导致进度和未使用金币永久丢失。如果你正在尝试解决问题，请先联系支持。恢复购买可恢复符合条件的永久装饰，但不会恢复金币余额或解谜进度。

游戏内没有专门的数据清除或账号删除按钮。开发者没有你存档的服务器副本，因此无法远程重置或恢复。

2. 移除本地 App 数据

  1. 在 iPhone 或 iPad 上打开设置 → 通用 → iPhone 储存空间 / iPad 储存空间 → Boxmello。
  2. 选择删除 App并确认。卸载 App会保留文稿和数据，因此并非同一操作。
  3. 检查安装了 Boxmello 的其他设备；每台设备可能有自己的本地存档。

这会从该设备移除 Boxmello 的 App 容器，包括本地存档与恢复文件。除非操作系统备份或迁移恢复了旧数据，否则重新安装会创建新存档。这不会删除你的 App Store 购买历史。

3. 单独管理备份

根据设置，App 数据可能保留在 iCloud 或电脑备份中。请在设备的 iCloud 备份设置中查看 Boxmello，如果也希望删除该副本，请移除其备份数据或将其排除在备份之外。Mac 或 PC 备份也需单独检查。Apple 菜单名称可能因操作系统版本而异；请参阅Apple iCloud 储存空间指南。删除备份可能影响其他数据的恢复，请检查你选择的内容。

4. 请求删除支持通信

请以Boxmello 隐私请求为主题，发送邮件至bayrambas255@icloud.com。如有可能，请使用之前联系支持时的邮箱地址，并提供：

  • 你的姓名。
  • 请求内容：删除、访问、更正或其他隐私权利。
  • 相关通信或大致日期。
  • 若与发件地址不同，请提供回复地址。

请勿主动发送密码、完整支付卡号或身份证件。我们可能要求合理验证或适用法律程序所需的详细信息。在符合法律条件时，我们会删除或匿名化开发者所持数据，并说明因法律义务或法律请求而必须保留的数据。请求会在适用法定期限内得到答复，包括土耳其 KVKK 适用时最长30天。

简单支持和删除请求可使用上述方式。正式 KVKK 申请应以土耳其语提出，从事先提供并在开发者处登记的邮箱地址发送，或使用适用公告允许的其他方式。公告第5条要求正式申请包含规定信息，例如姓名、请求内容、送达地址及相关身份信息。请参阅官方申请程序。请勿主动发送身份证件副本。

5. Apple 和 GitHub 记录

删除 Boxmello 或向开发者发送邮件不会删除 Apple 账单历史、Apple 账户数据或 GitHub 托管安全日志。对于它们控制的记录，请使用Apple 数据与隐私工具或GitHub 隐私声明中的联系方式。任何 Apple 备份副本也必须通过 Apple 设置另行管理。

删除本地存档本身不会取消购买、提交退款请求或撤销有效的永久装饰使用权。Apple 可能通过恢复购买再次提供该使用权。
