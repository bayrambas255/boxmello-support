你的隐私

隐私政策

关于 Boxmello 本地存档、Apple 服务、支持邮件和本网站的实用说明。本政策同时作为我们根据土耳其《个人数据保护法》（KVKK）提供的告知。

生效及最后更新日期：2026年10月14日 · v1.0

1. 谁负责处理数据？

Boxmello 由位于土耳其的Bayram Baş提供。对于开发者处理的个人数据，Bayram Baş 是数据控制者。联系方式：bayrambas255@icloud.com。

本政策涵盖当前 iOS/iPadOS 游戏、本支持网站及与开发者的通信。Apple 和 GitHub 也根据各自的隐私声明，为其自身服务处理信息。

2. 游戏中存储的数据

正常游玩 App Store 版本时，游戏存档不会发送到开发者的服务器。Boxmello 没有游戏账号、广告 SDK、第三方分析 SDK 或跨 App 跟踪。它不会请求访问你的位置、通讯录、相机或麦克风。

App 会存储随机生成的本地个人档案标识符、关卡进度、分数和星星、当前谜题状态、金币与辅助道具余额、装饰、每日奖励、教程状态及设置。它还会存储购买验证记录，例如商品与交易标识符、处理日期、退款状态及永久购买使用权。这些信息用于保存游戏、避免重复发放购买内容及应用已验证的购买变更。

存档及其恢复副本位于同一台设备，并非独立的云备份。根据你的设置，Apple 设备备份或迁移功能可能包含这些数据。开发者无法远程访问你的本地存档。

本地存档和 StoreKit 信息在设备上以电子和自动方式处理，用于提供游戏和验证购买，法律依据为土耳其 KVKK 第5条(2)(c)规定的履行合同。

3. 购买及 Apple 提供的信息

Apple 通过 StoreKit 处理 App Store 付款。Boxmello 在你的设备上接收经验证的交易和使用权信息，以发放购买内容并处理恢复或退款。开发者不会收到你的支付卡信息或 Apple 账户密码。

Apple 可能向开发者提供销售摘要、App 性能或崩溃报告。使用情况和崩溃信息的共享取决于 Apple 服务及你的设备选择，与 Boxmello 内的分析 SDK 不同。请参阅App 分析与隐私及Apple 隐私政策。可在 iOS 设置 → 隐私与安全性 → 分析与改进中查看共享选项。

开发者持有的诊断报告用于识别和修复故障，依据为土耳其 KVKK 第5条(2)(f)规定的正当利益，并与你的权利进行权衡。开发者持有的副本仅在调查和解决问题或履行法律义务、处理法律请求所需的期间保留，随后删除或匿名化。Apple 自行管理其服务中报告的保留期限。

4. 支持通信及法律依据

当你向开发者发送邮件时，你的邮箱地址、发件人姓名、邮件内容，以及你自行提供的附件或技术详情将通过 iCloud Mail 接收。通过邮件回复需要你的邮箱地址和足以说明问题的信息；无需联系支持也能游玩。请避免发送敏感个人信息。

支持数据用于回答你的请求、调查问题、协助购买、改进已报告的问题或处理隐私请求，不用于广告、邮件推广名单、出售个人数据或对你作出自动化决定。

5. 网站托管和 Cookie

本静态支持网站没有开发者添加的 Cookie、本地存储、广告、联系表单、嵌入式社交组件或访客分析工具。图片和样式随网站提供，不使用第三方字体服务。

本网站由 GitHub Pages 托管。GitHub 表示会出于安全目的记录访客 IP 地址，包括未登录状态下的访问。这些托管日志由 GitHub 管理，开发者不会通过本网站接收单个访客日志。请参阅GitHub Pages 数据收集说明和GitHub 隐私声明。打开外部链接会前往相应提供者的服务。

6. 接收方及境外处理

Apple 提供付款、平台报告、启用后的设备备份及 iCloud Mail 服务。GitHub 提供网站托管与安全服务。支持通信由 Bayram Baş 及传递邮件所用的服务处理。法律要求时，信息也可能披露给主管机关；法律请求需要时，也可能披露给专业顾问，但均限于必要范围。

支持邮件通过 Apple 的 iCloud Mail 接收和存储；邮件内容、发件人信息及附件可能在土耳其或你居住国以外的基础设施上处理。GitHub 也会在其国际基础设施上处理访客 IP 日志，以提供和保护本网站。Apple 和 GitHub 的隐私声明对这些服务作出说明。访问本网站或发送支持邮件不被视为同意国际数据传输。对于涉及开发者所持数据的具体传输，可向上述联系人询问。

7. 保留期限与安全

本地存档保留在设备上，直至 App 数据被移除；设备或云备份副本另行管理。支持通信仅在解决请求及相关后续事项、履行适用法律义务，或确立、行使、维护法律请求所需的期间保留。具体期间取决于问题、是否存在未解决争议，以及适用的法定保留期限或时效。不再用于上述目的的数据将被删除或匿名化。

Apple 和 GitHub 自行确定其控制的记录的保留期限。开发者持有的通信会采用合理保护措施，但任何存储或传输方式都无法保证绝对安全。请勿在支持邮件中包含密码、完整卡信息或不必要的身份证件。

8. 你的隐私权利

根据土耳其 KVKK 第11条，你可以询问数据是否被处理，要求了解处理情况、目的和用途，了解境内外接收方，在符合法律条件时要求更正、删除或销毁，并要求将这些更正或删除告知接收方。你可以对完全基于自动分析产生的不利结果提出异议，并要求赔偿违法处理造成的损失。Boxmello 不作出此类自动化决定。

其他适用法律也可能赋予访问、数据可携带、限制处理、反对和撤回同意的权利。你可以向相关数据保护机关投诉。有关土耳其，请参阅KVKK 权利指南。

请使用通信时的邮箱地址向开发者发送邮件，说明你的请求。我们可能要求适度验证及适用程序所需的详细信息。请求会在适用的法定期限内得到答复，包括 KVKK 适用时不迟于30天。因法律要求而必须保留数据的例外情况会予以说明。请参阅数据与删除指南。开发者无法查看或远程删除仅保存在你设备上的存档，也无法删除由 Apple 或 GitHub 控制的记录。

9. 儿童与家庭

儿童和其他玩家无需提供账号或个人资料即可游玩。我们不会要求儿童发送个人信息，也不将其数据用于广告。儿童的支持及购买问题应由家长或监护人处理。如果你认为儿童发送了个人信息，请联系开发者，以便审核并在适当情况下删除。请遵守 App Store 显示的年龄分级及适用的家长许可要求。

10. 可选的 Beta 版与游戏测试

TestFlight 或开发版本可能包含由研究人员启用的可选游戏测试模式。启用后，它会将参与者代码、游戏事件、时间和版本信息写入本地文件。这些文件不会自动上传；实验人员可以通过设备的分享菜单主动导出。正常 App Store 版本不会启用此模式。任何有组织的研究都必须在收集或导出研究数据前说明目的、接收方、保留期限及参与选择。Apple 的 TestFlight 服务有其自己的隐私条款。

上方日期标识本版本。数据处理方式变更时会更新本告知；法律要求的额外告知或同意必须在相关新处理开始前提供。问题和隐私请求请发送至：bayrambas255@icloud.com。
