데이터 관리

데이터 및 삭제

Boxmello 계정은 없습니다. 기기 저장 데이터, 지원 메시지 및 타사 기록은 각각 삭제 방법이 다릅니다.

시행 및 최종 업데이트: 2026년 10월 14일 · v1.0

1. 삭제하기 전에

앱을 삭제하면 진행 상황과 미사용 코인을 영구적으로 잃을 수 있습니다.문제를 해결하려는 경우 먼저 지원에 문의하세요. 구매 복원은 대상 영구 장식을 복원하며 코인 잔액이나 퍼즐 진행 상황은 복원하지 않습니다.

게임 내에 별도의 데이터 삭제 또는 계정 삭제 버튼은 없습니다. 개발자는 저장 데이터의 서버 사본이 없으므로 원격으로 초기화하거나 복구할 수 없습니다.

2. 로컬 앱 데이터 제거

  1. iPhone 또는 iPad에서 설정 → 일반 → iPhone 저장 공간 / iPad 저장 공간 → Boxmello를 여세요.
  2. 앱 삭제를 선택하고 확인하세요. 앱 정리하기는 문서와 데이터를 보존하므로 같은 작업이 아닙니다.
  3. Boxmello가 설치된 다른 기기도 확인하세요. 각 기기에 개별 로컬 저장 데이터가 있을 수 있습니다.

이 작업은 해당 기기에서 로컬 저장 데이터 및 복구 파일을 포함하는 Boxmello 앱 컨테이너를 제거합니다. 운영체제 백업이나 마이그레이션으로 이전 데이터가 복원되지 않는 한 재설치하면 새 저장 데이터가 생성됩니다. App Store 구매 내역은 삭제되지 않습니다.

3. 백업은 별도로 관리

설정에 따라 앱 데이터가 iCloud 또는 컴퓨터 백업에 남을 수 있습니다. 기기의 iCloud 백업 설정에서 Boxmello를 확인하고 해당 사본도 삭제하려면 백업 데이터를 제거하거나 백업에서 제외하세요. Mac 또는 PC 백업도 별도로 확인하세요. Apple 메뉴 이름은 운영체제 버전에 따라 다를 수 있습니다. Apple iCloud 저장 공간 안내를 확인하세요. 백업 삭제는 다른 데이터 복구에도 영향을 줄 수 있으므로 선택 항목을 확인하세요.

4. 지원 서신 삭제 요청

제목을 Boxmello 개인정보 요청으로 하여 bayrambas255@icloud.com으로 이메일을 보내 주세요. 가능하면 이전에 지원에 문의한 이메일 주소를 사용하고 다음 내용을 적어 주세요:

  • 이름과 성.
  • 삭제, 접근, 정정 또는 다른 개인정보 권리 요청 내용.
  • 관련 서신 또는 대략적인 날짜.
  • 발신 주소와 다른 경우 회신 주소.

요청받지 않은 암호, 전체 결제 카드 번호 또는 신분증을 보내지 마세요. 합리적인 확인이나 해당 법적 절차에서 요구하는 세부 정보를 요청할 수 있습니다. 법적 조건을 충족하면 개발자 보유 데이터를 삭제하거나 익명화하고 법적 의무 또는 청구 때문에 보관해야 하는 데이터는 설명합니다. 요청은 적용 법정 기한 내에 답변하며, 튀르키예 KVKK에 따른 경우 늦어도 30일 이내입니다.

간단한 지원 및 삭제 요청에는 위 방법을 이용할 수 있습니다. 정식 KVKK 신청은 튀르키예어로 작성하여 개발자에게 미리 제공하고 등록한 이메일 주소에서 보내거나 관련 고시에서 허용하는 다른 방법을 사용해야 합니다. 고시 제5조는 정식 신청에 이름, 요청 내용, 송달 주소 및 관련 신원 정보 등 정해진 사항을 포함하도록 요구합니다. 공식 신청 절차를 확인하세요. 요청받지 않은 신분증 사본은 보내지 마세요.

5. Apple 및 GitHub 기록

Boxmello 삭제나 개발자에게 이메일을 보내는 것으로 Apple 결제 내역, Apple 계정 데이터 또는 GitHub 호스팅 보안 로그가 삭제되지는 않습니다. 각자가 관리하는 기록에 대해서는 Apple 데이터 및 개인정보 보호 도구 또는 GitHub 개인정보 처리방침에 안내된 연락 방법을 이용하세요. Apple 백업 사본도 Apple 설정에서 별도로 관리해야 합니다.

로컬 저장 데이터 삭제 자체는 구매 취소, 환불 요청 또는 유효한 영구 장식 이용 권한의 취소가 아닙니다. Apple은 구매 복원을 통해 해당 권한을 다시 제공할 수 있습니다.
