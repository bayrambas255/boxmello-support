آپ کا ڈیٹا اور حذف کرنا

Boxmello اکاؤنٹ نہیں۔ آلے کا محفوظہ، معاونتی پیغامات اور تیسرے فریق کے ریکارڈ کے حذف کرنے کے طریقے مختلف ہیں۔

نافذ اور آخری تازہ کاری: ۱۴ اکتوبر ۲۰۲۶ · v1.0

۱. حذف کرنے سے پہلے

ایپ حذف کرنے سے پیش رفت اور غیر استعمال شدہ سکے مستقل ضائع ہو سکتے ہیں۔ مسئلہ حل کرنا ہو تو پہلے معاونت سے رابطہ کریں۔ خریداری بحال کریں اہل مستقل سجاوٹ بحال کرتا ہے، سکوں کا بیلنس یا پہیلی کی پیش رفت نہیں۔

کھیل میں الگ ڈیٹا یا اکاؤنٹ حذف کرنے کا بٹن نہیں۔ ڈویلپر کے پاس محفوظے کی سرور نقل نہیں اور اسے دور سے ری سیٹ یا بازیاب نہیں کر سکتا۔

۲. مقامی ایپ ڈیٹا ہٹائیں

  1. iPhone یا iPad پر ترتیبات → عمومی → iPhone اسٹوریج / iPad اسٹوریج → Boxmello کھولیں۔
  2. ایپ حذف کریں (Delete App) منتخب کرکے تصدیق کریں۔ ایپ آف لوڈ کریں (Offload App) دستاویزات اور ڈیٹا رکھتا ہے، اس لیے یہ مختلف عمل ہے۔
  3. Boxmello والے دوسرے آلات بھی چیک کریں؛ ہر ایک کا اپنا مقامی محفوظہ ہو سکتا ہے۔

اس سے آلے سے Boxmello کا ایپ کنٹینر، مقامی محفوظات اور بازیابی فائلیں ہٹتی ہیں۔ دوبارہ انسٹال کرنے سے نیا محفوظہ بنتا ہے، جب تک آپریٹنگ سسٹم کا بیک اپ یا منتقلی پرانا ڈیٹا نہ لائے۔ App Store خریداری کی تاریخ نہیں مٹتی۔

۳. بیک اپ الگ سنبھالیں

ترتیبات کے مطابق ایپ ڈیٹا iCloud یا کمپیوٹر بیک اپ میں رہ سکتا ہے۔ آلے کی iCloud بیک اپ ترتیبات میں Boxmello چیک کریں اور وہ نقل بھی حذف کرنی ہو تو اس کا بیک اپ ڈیٹا ہٹائیں یا خارج کریں۔ Mac اور PC بیک اپ الگ دیکھیں۔ آپریٹنگ سسٹم کے مطابق Apple کے مینو نام بدل سکتے ہیں؛ Apple کی iCloud اسٹوریج رہنمائی دیکھیں۔ بیک اپ حذف کرنے سے دوسرے ڈیٹا کی بازیابی متاثر ہو سکتی ہے، لہٰذا انتخاب چیک کریں۔

۴. معاونتی خط و کتابت حذف کرنے کی درخواست

bayrambas255@icloud.com کو Boxmello رازداری کی درخواست کے موضوع سے ای میل کریں۔ ممکن ہو تو سابقہ معاونتی پتہ استعمال کرکے بتائیں:

  • اپنا نام اور خاندانی نام۔
  • درخواست: حذف، رسائی، درستگی یا دوسرا رازداری حق۔
  • متعلقہ خط و کتابت یا اندازاً تاریخیں۔
  • بھیجنے والے سے مختلف ہو تو جواب کا پتہ۔

بغیر مانگے پاس ورڈ، مکمل ادائیگی کارڈ نمبر یا شناختی دستاویز نہ بھیجیں۔ معقول تصدیق یا لاگو قانونی طریقے کی ضروری تفصیلات مانگی جا سکتی ہیں۔ قانونی شرائط پوری ہوں تو ڈویلپر کا ڈیٹا حذف یا بے نام کریں گے اور قانونی ذمہ داری یا دعوے کے لیے رکھنا ضروری ہو تو بتائیں گے۔ جواب قانونی مدت میں دیا جاتا ہے، ترکیہ کے KVKK کے تحت زیادہ سے زیادہ ۳۰ دن میں۔

عام معاونت اور حذف کی درخواست اوپر کے طریقے سے کر سکتے ہیں۔ رسمی KVKK درخواست ترکی زبان میں اور اس ای میل سے ہو جو پہلے ڈویلپر کو دی اور اس کے پاس درج ہو، یا لاگو اعلامیے کے کسی دوسرے مجاز طریقے سے۔ آرٹیکل 5 رسمی درخواست میں مقررہ تفصیلات مانگتا ہے، جیسے نام، درخواست، نوٹس کی ترسیل کا پتہ اور متعلقہ شناختی معلومات۔ سرکاری درخواست کا طریقہ دیکھیں۔ بغیر مانگے شناختی دستاویز کی نقل نہ بھیجیں۔

۵. Apple اور GitHub ریکارڈ

Boxmello حذف کرنا یا ڈویلپر کو ای میل Apple کی بلنگ تاریخ، Apple اکاؤنٹ ڈیٹا یا GitHub ہوسٹنگ حفاظتی لاگز نہیں مٹاتا۔ ان کے اختیار کے ریکارڈ کے لیے Apple کے ڈیٹا اور رازداری ٹول یا GitHub کے رازداری بیان کے رابطے استعمال کریں۔ Apple بیک اپ نقل بھی Apple ترتیبات سے الگ سنبھالنا ہوگی۔

مقامی محفوظہ حذف کرنا خود خریداری منسوخ، رقم واپسی کی درخواست یا جائز مستقل سجاوٹ کا حق ختم نہیں کرتا۔ Apple خریداری بحال کریں سے وہ حق دوبارہ دے سکتا ہے۔
